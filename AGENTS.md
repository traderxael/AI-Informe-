# AGENTS.md — Base44 dev environment notes

## What this app is
AI Informe — a TanStack Start (React 19) + Vite dashboard showing weekly AI news
signals by region and model. Data is static JSON in `public/` (generated by Python
scripts in CI, not needed for local dev).

## How it runs here
- **Single service** in `docker-compose.base44.yml`: `node:22-slim` with the repo
  bind-mounted at `/workspace`. Runs `npm install` then `npm run dev` (Vite dev
  server on container port 8080, mapped to host 3000).
- **No external database.** The app uses PGLite (embedded Postgres compiled to
  WASM) as its DB backend when `DATABASE_URL` is unset. Setting `DATABASE_URL`
  switches to a real Postgres/Neon pool — not needed for preview.
- **Auth is disabled** in preview via `VITE_AUTH_ENABLED=false` (set in compose
  `environment:` and mirrored in `.grok/app-env.json`). This selects a dev user
  and avoids the auth broker (`auth.grok.me`). To enable real federated sign-in,
  remove the flag and inject `GROK_AUTH_CLIENT_ID` / `GROK_AUTH_CLIENT_SECRET`.
- **No external secrets required to boot.** The Python LLM scripts
  (`scripts/resumir_con_llm.py`) optionally use `MOONSHOT_API_KEY` etc., but
  those are only used by the GitHub Actions pipeline, not the web app.

## Key files
- `vite.config.ts` — Vite + TanStack Start + Nitro config. Dev server binds
  `0.0.0.0:8080` (contract — don't change port). Custom plugins handle PGLite
  bootstrap, auth popup, PWA, and `/__app-env`.
- `src/lib/db.ts` — PGLite/Neon dual-backend. Auto-applies `migrations/*.sql`.
- `src/lib/auth/server.ts` — Better Auth config. Frozen/pre-wired; do not rewrite.
- `src/lib/informe-data.ts` — loads signals from static JSON in `public/data/`.
- `scripts/with-app-env.mjs` — wraps `vite dev/build/preview`, merges
  `.grok/app-env.json` (VITE_-prefixed keys only) into the environment.

## Verifying it works
- `curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:3000/` → 200
- The dashboard should show signal cards (222 signals, 9 countries).
- Data files: `/data/signals-first.json`, `/data/signals-rest.json`, `/signals.json`.

## Quirks
- `.grok/` is gitignored, so `.grok/app-env.json` lives only in the sandbox
  workspace, not in git. The compose `environment:` entry for `VITE_AUTH_ENABLED`
  is the reliable source.
- `playwright` is a devDependency; browser download is skipped via
  `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1` (not needed for the dev server).
- `node_modules` persists in the bind mount, so restarts skip `npm install`
  after the first boot (it still runs but is fast).
